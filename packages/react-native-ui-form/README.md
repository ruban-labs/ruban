# @ruban-labs/react-native-ui-form

Composable Field, Input, Textarea, Checkbox, RadioGroup, and Select controls for bare React Native.

[简体中文](./README.zh-CN.md)

```sh
npm install @ruban-labs/react-native-ui-form @ruban-labs/react-native-ui-theme
```

Import from the root or stable subpaths such as `@ruban-labs/react-native-ui-form/input` and
`@ruban-labs/react-native-ui-form/radio-group`. Shared Field state keeps labels, descriptions,
errors, disabled state, and accessibility semantics aligned.
