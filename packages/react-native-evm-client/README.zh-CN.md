# @ruban-labs/react-native-evm-client

[English](./README.md)

面向 bare React Native 的快速 EVM RPC 与资产概览基础能力。它会并发竞速健康节点、
合并重复请求、批量读取余额，并按链增量回传结果，让应用先展示缓存，再逐步替换实时数据，
不必等待最慢的网络。

内置链配置只是可替换的默认值。正式应用仍需独立评估节点、索引器和价格源的条款与容量。

每个 RPC 请求必须声明来源是 App 内部功能，还是某个浏览器会话。两种来源使用独立的
并发通道、请求合并命名空间和节点健康评分。来源信息只参与本地调度，绝不写进发往公开
RPC 节点的 JSON-RPC Payload。
