# @ruban-labs/react-native-ui-dialog

Composable dialogs for bare React Native, built on Ruban Theme and Overlay peers.

[简体中文](./README.zh-CN.md)

```sh
npm install @ruban-labs/react-native-ui-dialog @ruban-labs/react-native-ui-overlay @ruban-labs/react-native-ui-theme
```

Use `Dialog.Root`, `Dialog.Trigger`, `Dialog.Content`, and `Dialog.Close` to build controlled or
uncontrolled dialogs. Add one `OverlayProvider` at the application root.
