# @ruban-labs/react-native-ui-sheet

Bottom-sheet and selection-sheet primitives for bare React Native.

[简体中文](./README.zh-CN.md)

```sh
npm install @ruban-labs/react-native-ui-sheet @ruban-labs/react-native-ui-overlay @ruban-labs/react-native-ui-theme react-native-safe-area-context
```

The package shares Ruban's single overlay host and declares Safe Area Context as a peer, keeping
that native dependency explicit in the consumer application.
