## Try Ruban

Download the `.apk` below, open it on Android and allow installation from your browser when prompted.
Choose **Try example** on first launch to explore a synthetic portfolio without an API key or paid requests.
The example is labelled **Sample data · offline**. It is not a real address balance.

For real addresses, add your own DeBank Cloud AccessKey in **Settings → Data source**,
then add a watch address and refresh. DeBank usage is billed to your account.
Cached portfolios remain available without another request; no shared API key is shipped.
You can return to the example from Settings without replacing your saved key or real portfolios.

This is an early Android website preview, separate from the older store release.
It uses the production app ID `com.rubanlabs.mobile` and the website app-signing certificate,
not the Play upload key. Same-ID installation requires matching signing certificates and
a non-downgraded version code. Do not uninstall a populated installation just to downgrade.
Back up important data before changing channels. Avoid importing funded private keys into this preview.

`SHA256SUMS` verifies the APK download. `release.json` identifies the exact commit, build,
channel and signing-certificate fingerprint. Release assets exclude source maps and signing material.
