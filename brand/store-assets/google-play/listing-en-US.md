## Full description

Ruban is a focused React Native component workbench for exploring clear, composable interface patterns.

Browse a growing catalogue of source-owned components, open live examples, and inspect variants, sizes, states, and semantic tones. The Playground brings typography, color, spacing, layout, and interaction specimens together in one place, with light and dark themes available for comparison.

Ruban keeps the experience practical:

• Explore buttons, cards, badges, separators, switches, and more
• Compare component behavior across themes
• Review design tokens and visual specimens
• Inspect build and React Native compatibility information
• Open deterministic component examples through deep links

Ruban Labs builds small, focused tools for bare React Native projects. The app is our public workbench: a place to demonstrate components, validate design decisions, and show how each tool behaves in a real application.

No Expo or platform-specific foundation is required by Ruban libraries. Each tool is designed to stay composable, focused, and suitable for bare React Native applications.
